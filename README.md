## 🌟 Overview

This repository hosts the official documentation for the **Djazair Programming Language** at [djazair-language.github.io](https://djazair-language.github.io/).

It features:
- **Comprehensive Language Guide:** Variables, types, operators, strings, arrays, maps, pattern matching, loops, functions, OOP, exceptions, and DPM.
- **First-Class Unicode & Arabic:** In-depth explanations of Arabic identifiers, emojis, and code-point accurate manipulation.
- **20 Standard Library Modules:** Full API references and practical examples for all 20 stdlib modules.
- **C/C++ Embedding Guide:** Integrating `djazair.h` into host applications.
- **Interactive UI:** Dark/Light theme switching, instant `Ctrl+K` search, copy code buttons, and responsive drawer navigation.

---

## 🚀 Building the Site

The documentation is generated using a fast, zero-dependency Python build generator:

```bash
python build.py
```

This compiles all documentation pages, generates the search index (`assets/js/search-index.js`), and creates the SEO sitemap.
